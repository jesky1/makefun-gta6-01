**Caldera Heat** — an original open-world crime game that plays in a desktop browser from static files, no network requests. Explore Caldera Bay on foot and by car across six districts: steal cars, run traffic, dodge or fight the police through a five-star wanted system, work a six-job story chain for fixer Lu Vane, grab stash crates, earn taxi fares, clear your heat at the spray shop, and save your run. WebGL low-poly city with lit windows, a live HUD and minimap, procedural audio, and deterministic seeded simulation — the same seed always plays the same city.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Controls: WASD/arrows to move and drive, Shift to sprint, E to enter/exit cars and interact, F or click to fire, R to reload, S to save, L to load, P to pause, M to mute.
